# QORGAN AI — Қорған AI

QORGAN AI — қазақ және қазақ-орыс аралас тілдеріндегі интернет-алаяқтық,
фишинг және күмәнді хабарламаларды машиналық оқыту әдістерімен автоматты
анықтауға арналған интеллектуалды веб-платформа.

## QORGAN AI мүмкіндіктері

- SMS, WhatsApp және Telegram хабарламаларын талдау
- Қазақ және аралас тілдегі мәтінді тексеру
- Алаяқтық ықтималдығын анықтау
- Қауіп деңгейін көрсету
- Күмәнді белгілерді анықтау
- Скриншоттағы мәтінді OCR арқылы оқу
- Қазақ, орыс және ағылшын мәтіндерін OCR арқылы тану

## Технологиялар

- Python
- Streamlit
- Machine Learning
- TF-IDF
- Naive Bayes
- Tesseract OCR
- scikit-learn
